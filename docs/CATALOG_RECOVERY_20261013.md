# 点单目录恢复与库存视觉排序

供应商新商品缺少其他语言字段导致第二页读取失败。统一服务端在共享目录提供缺失语言回退，保留已有翻译、图片、售价、库存及历史快照。图片批量过程兼容不同数据库标识字符规则，缩略图恢复；客户端仍按不可变附件编号持久缓存，签名变化不重新下载。

点单首次失败显示商品目录专用提示和触屏刷新按钮，不再误报桌台读取失败。背景失败保留已显示目录。同一分类的商品按可售在前、无库存在后排序，组内保持原次序；多规格只要一种可售就列入可售区域。无库存商品图片、名称、规格、可售文字和价格统一为 35% 不透明度，有库存保持正常。原无库存加号／规格按钮隐藏规则保持。

验证：目录恢复、分页分组、跨分类库存排序、多规格局部售罄／全部售罄、四语言四行布局、PNG 路径及本地持久缓存共 21 个相关测试通过。后端全量测试及真实素材下载核对通过。Android 11 ARM32 构建按目标设备原证书重签、install -r -t 保留数据升级；实机截图确认菜单及瓶图恢复。未修改其他手机应用和门店交易数据。
