# 收银员工消费明细（代码接通，未线上验收）

LiveTablesPanel 对有 orders.read 的独立员工显示“消费明细”，无场次或无该权限不显示入口。
LiveOrdersPanel 调用加密超级接口 K260929001905，门店只能来自当前员工会话，桌台和
场次固定为打开时的服务端快照，不随本桌下一场次自动切换。

支持四语言成交名称/规格、数量、单价、小计、订单金额和原始后台状态。只读；没有收款、
核销、退款或上菜成功按钮。不把 pending 合计当最终账单，也不按本机时间宣布支付过期。
分页每次重新读当前服务端快照，不宣称跨页同一时刻；重复游标、乱序、金额不符、缺明细、
跨门店/桌台/场次响应及非法状态均拒绝。金额用整数分显示，数据不落普通磁盘缓存。

手动刷新、回前台及实时变更提示后重新查询；通知有 400ms 合并和在途后一次补查。
切后台立即清空，迟到响应丢弃。员工会话通知会清掉明细，登录/刷新改变会话后由父页面
重新建工作台；订单请求自身另有会话 epoch 检查，退出后不得接受旧响应。

测试使用本地 test-only 数据，没有真实门店记录或支付请求。真实后端需迁移 173–177、
核对权限及按审批启用接口/实时通道，不能因 UI 可打开就认定线上接口已经启用。
本节点未安装设备、部署服务、执行数据库迁移或授予员工权限。

验证：Flutter analyze 无问题；完整测试 69 项通过、1 项可选截图测试跳过。
ARM32 release APK 构建成功（15.3MB，24.5 秒），CASHIER_PREVIEW=false、
CASHIER_REALTIME=true；仍为独立预览应用及开发签名，不是正式生产签名或营业验收包。
源代码纳入首次检查点，范围和推送核查见 SOURCE_CHECKPOINT.md；没有覆盖既有开发内容。
