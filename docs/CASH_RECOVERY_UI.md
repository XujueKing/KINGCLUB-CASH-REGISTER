# 现金请求恢复界面

新增LiveCashRecoveryPanel和工作台payment.cash权限入口，初始仅加载本设备当前员工安全日志，不自动查网络或执行付款。显示订单、原请求、应收，以及本机已收现金/未收款终止决定；本地记录不冒充服务器确认。

操作：查回原请求；原准备未知时可经明确对话框查回并重试原准备；已知意图且查回允许确认后可核对实收；未记录收妥现金时可明确声明未收现金后终止。收妥与终止调用既有控制器，不能互换。实收按整数分解析，最多两位小数，范围不超过100000000分且不低于应收，显示找零。已保存实收锁定不可改。终止提示明确不是退款或取消订单。

所有按钮在请求/对话框期间互斥。身份变化与非前台状态使epoch失效、清除页面数据并关闭当前确认弹窗，旧对话框不能继续发送。OS暂停渲染后不能用Flutter控件树证明系统快照已经隐藏；不宣称实现系统任务快照防截屏。恢复前台重新加载本地日志，不自动重发收款。

异常只显示通用未确认/存储不可读提示，不泄漏SQL或私有异常；查回/金额不一致不当成付款失败，保留原请求。恢复列表空只在读取成功时显示。前台结果显示服务器确认或原意图关闭；关闭不声明整张订单未付。

四语言简中/英文/繁中/泰语新增25条文案，1024×600布局测试覆盖每种语言的金额对话框和成功反馈。11项widget测试覆盖必须先查回、低金额禁止、找零、明确终止、身份变化、inactive→paused→resumed弹窗失效、在途禁用、付款异常后的已收状态和工作台入口。完整flutter test为205项通过、1项可选截图跳过，flutter analyze无问题。

此处只处理已保存的原现金请求，新订单发起现金准备的UI入口还未接，因此不能宣称完整收款闭环。尚未安装真机或进行真实支付/公网验收；后端仍默认禁用。下一步需订单收款入口、真机触控/扫码打印及正式签名等验证。
