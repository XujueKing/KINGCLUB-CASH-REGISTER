# 账号密码登录

登录页只展示员工账号和密码，不再要求服务地址或门店 UUID。实际 HTTPS 服务入口由安装包的 CASHIER_SERVICE_URL 构建参数提供，真实地址不进入源码。发布人员可用 scripts/build-cashier.ps1 验证地址并构建；不得分发未配置入口的员工版安装包。

1901 首次登录不传 storeRef。后端验证密码后，单个有效门店直接返回会话；多门店返回 requiresStoreSelection=true 和 stores（storeRef、storeName），此时尚无业务会话。客户端展示门店名称，选定后通过加密接口重新提交账号密码和所选 storeRef；服务器再次校验密码及当前授权。取消选择不保存会话，密码不写磁盘。选择等待最多两分钟。

原员工会话仍严格绑定门店；刷新和恢复继续核对原门店。旧版显式 storeRef 登录保持兼容。新增服务端目录迁移 244 必须与后端登录实现配套，只有 UI 更新不能替代接口升级。

本次不修改桌台最低开台人数，也不增加真实交易开关。登录成功和工作台完整可用仍需分别验收。

验证：登录相关 26 项测试通过，analyze 无问题，ARM32 release 构建通过。目标收银机旧包、新包证书 SHA-256 一致，使用 install -r 保留数据升级。APK 内已核对正确服务入口；设备页面只有账号、密码两个输入框，真实员工登录成功并进入工作台。后端 244 和新版登录模块已上线，真实加密请求省略 storeRef 的登录成功。桌台读取仍被缺失 minimumSeats 的现有配置阻塞，多门店现场验收尚未执行。
