# 触屏改价与扫码授权（2026-10-03）

默认进入折扣按钮页，提供常用折扣；改价使用内置数字键盘，不弹系统键盘。免单和恢复原价为独立按钮。打开时保留当前价格，选择后显示单价、数量和小计；点击确定后扫描负责人动态 KING 会员码，授权成功才应用。

统一调用 `K261003002002`。本店 `price.adjust` 管改价、折扣和恢复原价，`price.waive` 管零价；收银员的点单权限不等于授权权限。现有员工关联已有会员 userAccount，不创建新会员号。扫码赠送承担人与扫码审批是不同用途。

授权绑定操作员工及登录会话、门店、桌台场次、商品、原单价、新单价和赠送承担人。两小时内同一商品卡片的数量调整沿用已授权单价；改变范围需重新扫码。服务端每次写订单重新检查负责人状态、门店权限及版本；权限撤销立即阻止尚未提交的修改。授权过期请重新点击商品价格并扫码，不自动放行。

授权编号随本地商品行和待提交请求保留，原二维码不落本地。成交订单快照记录授权编号、授权会员账号、授权员工、授权时间、原价、实际单价、操作员和赠送承担人。已下单改价继续使用原调整记录，已付款不直接改价。

实际成本来自原订单关联的库存出入库批次记录，缺失成本不当作零。此批提供记录和追溯关联，未新增成本报表页面。

设备发布：同证书保留数据升级已完成；员工登录、默认折扣按钮和确认后的负责人扫码窗口已实机检查。临时商品已移除，未提交订单、扣款或退款；现场负责人实扫成功尚未由用户确认。

## USB 无焦点扫码修正

Android Activity 在 Flutter 焦点分发前接收外接 USB HID 键盘扫码，Enter/Tab 或 250ms 收尾；仅前台且存在扫码监听时启用，后台清除未完成输入，最长 512 字符，不保存码原文。商米广播保留，双通道相同码 500ms 内去重。Flutter 共用一个原生广播订阅；仅当前扫描路由处理结果。授权窗口删除输入框，普通免单删除赠送承担人入口，确定后直接负责人授权。

已用事件通道测试无输入框、失焦后扫码仍触发授权，价格/点单相关 31 项回归通过。USB 硬件实扫需现场确认，不以模拟事件冒充扫码器验收。

安装：已核对 SUNMI 旧包与新包证书一致，保留数据升级成功。
