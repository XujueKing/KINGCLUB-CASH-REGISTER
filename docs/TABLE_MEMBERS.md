# 桌台关联会员

开台弹窗可连续扫码，确认开台后保存关联。已开台时点击消费明细人数旁「关联会员」，直接扫码追加，无需输入框焦点。

一桌多个会员，会员可关联多桌；重复扫码自动去重。使用既有 userAccount，不增加人数、不改变 AA 入座、不指定付款人，不自动扣款。

开台已成功而关联失败时，只重试关联，不重新开台。原始动态码只在弹窗内存暂存，离开或退后台清除。关联场次、会员、操作员工及时间保留在服务器，供后续积分返利消费归属使用。
