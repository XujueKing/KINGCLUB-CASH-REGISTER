# 员工会话模型、存储与状态控制

状态：本地会话层及独立员工登录页面已接通；冷启动恢复、前台临期续期与前台定时刷新已接入。尚未连接生产后台，后台员工接口仍默认禁用。没有真实账号授权、交易、核销或设备安装。

## 校验与隔离

StaffSession严格验证独立E员工编号、UUID会话/key/安装实例、授权门店、已知权限集合、43字符随机密钥/令牌及访问/绝对刷新期限。只接受workbench.read，拒绝未知/重复权限；不把会员U编号当员工。服务地址强制HTTPS并绑定于会话，密码不进入持久化载荷，模型默认toString不包含字段。

冷启动/前台恢复需调用StaffAuthController.restore，读取缓存后先向原服务刷新。恢复过程中没有已认证session，不提供离线授权；刷新前删除旧缓存token，防止应用崩溃后自动重放。服务返回的员工、sessionId、apiKeyId和门店必须一致，绝对期限不得延长；失败要求重新登录。该策略在网络短暂故障时也可能需要重新输入密码，是避免重复刷新和离线伪授权的明确取舍。

## 安全存储

使用固定版本[flutter_secure_storage10.3.4](https://pub.dev/packages/flutter_secure_storage/versions/10.3.4)，Android独立storageNamespace，RSA-OAEP包装与AES-GCM默认算法；resetOnError=false，不静默重置、不降级普通SharedPreferences，不备份迁移材料。设备实例UUID使用系统安全随机数，在同一安全存储中保存；它只是安装实例，不是设备审批或硬件证明。

Android保留allowBackup=false，补充fullBackupContent=false及Android12+云备份/设备迁移排除规则。真实Keystore是否硬件支持、厂商迁移行为及重启恢复仍待目标设备测试，不因插件文档宣称已验证硬件级安全。

所有存储操作串行执行。保存前后检查会话代次；退出或销毁导致迟到保存时删除刚写入的旧会话，排队删除不会被迟到写入覆盖。存储异常向上报告SECURE_STORAGE_FAILED，不保留“已登录”内存状态。删除失败不承诺本机数据已移除，必须提示处理；远端退出仍尝试执行。

## 退出与经营查询

退出立即清空当前内存身份并关闭认证请求，删除本地会话后尝试1904，只在loggedOut=true时返回远端已确认；失败显示REMOTE_LOGOUT_UNCONFIRMED。未知登录/刷新结果可能已在服务端提交，不声称关闭客户端等于撤销服务端会话。再次登录依照服务端同员工同实例替换规则或绝对期限失效处理。

readWorkbench固定请求会话内门店，访问过期/认证忙碌时拒绝查询，返回前再次校验代次，防止旧桌台响应进入下个员工会话。只读桌台模型及分页页面现已本地接入，见LIVE_TABLES.md；WebSocket更新尚待接入。

## 登录页面增量

- 非演示启动进入StaffAccessPage；演示退出先明确提示清空演示草稿及验证本机已存会话，再替换路由，不将演示桌台带入真实登录。
- 输入HTTPS服务地址、门店编号、独立员工账号和密码，不内置生产地址。密码遮蔽、禁用建议/自动纠正，提交立即清空输入框，退后台也清空；不持久化密码。
- 初次启动仅通过服务端刷新恢复身份；已有前台会话在到期前一分钟刷新，后台取消计时，返回前台如临期则刷新。不因每次短暂失焦重复刷新令牌。
- 忙碌时禁止重复登录，错误不展示服务器原文、凭证或请求数据；安全存储失败和远端退出未确认有独立提示。
- 登录后现进入只读桌台页面，显示已验证员工、门店和服务端分页快照，不开放开台、下单、支付按钮。
- 四语言登录文案与1024×600横屏测试已加入；额外验证HTTP地址拒绝、提交密码清除、忙碌禁用及错误脱敏。测试替身仅在test目录，不提供生产降级。
- 此增量未重新构建或安装APK；下方APK哈希属于此前会话层构建，不包含本次登录页面。
