# 断网后的员工会话恢复

现场收银机全屏正常，但服务器不可达后回到员工登录页。源码显示刷新前删除本地旧凭证，连请求未发出的网络错误也会清空凭证。本批仅在 TRANSPORT_FAILED 且 deliveryUncertain=false（确定未发送刷新）时，将尚可刷新的原凭证恢复到系统加密存储，显示“重新连接”。按钮重新向服务器认证，无需再输入密码；不暴露离线员工身份、业务数据或操作权限。

发送结果不明、身份变化、权限拒绝、到期和储存失败仍不能重放旧凭证。刷新可能已在服务端轮换令牌时保持原登录要求。退出登录清理恢复入口和凭证，迟到存储以会话世代校验避免覆盖新登录。
