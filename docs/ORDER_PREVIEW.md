# 单笔订单屏幕预览（2026-09-29）

订单明细页新增“单笔订单预览（未打印）”。直接复用 1905 经 OrderSnapshot/LiveOrder 严格解析后的订单，不另起缓存/接口，不从截图或测试数据生成真实业务记录。

展示四语言商品名与规格、数量、单价、逐项金额、当前单笔总额、服务端订单状态及查询时间。待付款/已付款/已过期分别展示现有服务端枚举；醒目标注不是整桌结账单、收款凭证或发票。已付款枚举不被扩展解释为渠道到账证明，预览本身不改变任何状态。

实现为可滚动 Flutter 屏幕预览，尚不是打印点阵/ESC-POS 输出。没有文件导出、磁盘缓存、会员资料、付款码、打印通道、钱箱/切纸操作，也不发起新经营请求。未来业务打印必须另接授权凭证和持久化打印任务，不能直接把此订单快照当收款回执。

安全与失效：

- 只能预览当前已加载快照内的订单；加载中、经营操作忙碌、后台、无会话或已到期时不能打开。
- 单次打开互斥；生成弹窗首帧前再次比较页面 epoch，身份/实时版本失效时不显示旧单。
- 员工通知、后台切换、访问期限到期时移除预览内容，不在恢复前台时重新露出；桌台/场次/实时版本改变时原页面关闭弹窗并重读。
- 金额直接取经过逐项求和验证的整数分字段，不把当前分页金额宣称为整桌应付。

验证：20 项新增 widget 测试覆盖四语言×三订单状态、三种失效原因、四语言入口/实时关闭、首帧身份竞争；全量 467 项通过、5 项可选跳过，analyze 无问题。订单/会话为明确测试替身，不能据此声称真实员工、1905 HTTPS 同次端到端或安卓业务验收完成。

尚未安装本轮版本或执行真实打印；真实订单真机验收、完整整桌结账、实际收款和渠道核销保持未完成。

android-arm release 构建成功，CASHIER_PREVIEW=false、CASHIER_REALTIME=true；包含此前会话到期修复，仍使用开发签名，不是正式发布包。
