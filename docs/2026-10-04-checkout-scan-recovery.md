# 收款失败后的扫码恢复

收款异常后自动只读查询原请求；服务器确认仍是 prepared 才恢复付款码输入，pending/unknown 或查询失败继续保留恢复原单操作。不重新发送刚才的付款码，不清除原请求，不创建替代收款。

订单超时显示明确的未扣款提示，引导取消本次未发送收款后重新下单。付款期限由服务器判断，客户端不延长订单有效期。

19 项结账对话框测试通过，包括 prepared 恢复输入但不重付，以及 pending 不恢复输入。静态分析无错误，保留原有 3 项提示。此次按设备已安装版本的隔离构建目录打包，不带入并行开发的其他功能。

本机 Java 构建曾因 Unix domain socket 临时路径无法连接而失败，构建进程临时指定工作区 `build/jtmp` 后继续；不修改系统网络或全局 Flutter/JDK 配置。
