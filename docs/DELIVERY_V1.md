# V1 交付记录

2026-09-29。范围：首轮横屏界面、本地交互、受限服务就绪检查，不是营业版。

## 已实现

- 深绿/米白横屏工作台，桌台网格、区域/状态筛选、桌号搜索、详情侧栏。
- 分类商品、名称搜索、规格选择、售罄禁止选择、逐桌独立草稿、增减数量、清空确认、备注、整数分合计。
- 结账核对面板：明确草稿估算，不执行付款；订单样例筛选和详情。
- 会员和交班入口明确未接入，不制造会员资料或营业报表。
- 简中/英文/繁中/泰文资源切换，1366×768 与 1024×600 布局测试。
- 默认真实模式为空；演示模式常驻警示，退出销毁样例草稿。内存草稿退出进程不保留。
- HTTPS 服务 /ready 检查：无登录、无 token、禁止重定向、8 秒总超时、32KiB 应答上限；演示模式禁止网络检查。
- 独立 Android 包、32 位 ARM、横屏、禁备份及明文网络；无手机会话接管、无新增后台。

## 验证

自动测试覆盖真实模式无样例、规格金额与草稿隔离、数量上限、售罄/清台拒绝编辑、演示清理、URL 限制、四语言、点单及付款按钮禁用。10 项常规测试通过。

另外单独执行本地截图渲染测试并人工查看桌台、商品点单、结账核对三个页面。截图来自 Flutter 测试渲染器，使用本机字体和 Material Icons；不是收银机截图，不代表触控/字体/性能真机验收。图片存于被忽略的 artifacts/，字体不进入 Git。

ARM32 调试 APK 已构建成功。目标设备明确指定为用户连接的 SUNMI D2_2nd-SQB，安装返回：

```text
Failure [-500: prohibit Installation due to SQB Limitation.]
```
