# 本地测试单预览（2026-09-29）

打印机检查入口新增独立测试单预览，无需员工登录。仅固定非交易文字，不读取订单、会员或渠道信息；没有打印、连接、切纸或钱箱操作。

- 简中、英文、繁中、泰语可切换；384/512/576 是候选点宽，不代表 XP-80U 实际打印头宽度已经验证。
- PNG 显示实际二值点阵；Android 像素转换通过 compute 在后台 isolate 执行，字体布局仍在 Flutter 图形环境完成。
- 切换参数立即移除旧图，生成期间禁用参数输入；失败显示脱敏提示并允许重试，关闭后忽略迟到结果。
- 六项新增 widget 测试覆盖四语言失败布局/重试、参数传递及旧图清除、处理中关闭。成功预览测试使用真实渲染图片夹具，但参数选择测试不冒充对应纸宽实机验收。
- 既有 renderer 测试逐像素比较 PNG 与二值点阵，已在 compute 改造后通过。

验证：flutter analyze 无问题；全量 441 项通过、5 项可选测试跳过；android-arm release 构建成功（CASHIER_PREVIEW=false、CASHIER_REALTIME=true，仍为开发签名）。这些结果不是打印机物理输出验收。

本阶段不含实际 USB 数据输出、真实小票或支付成功证明。新预览界面尚未安装到收银机；Android 字体、触摸性能和实际纸张效果仍需分别验收。生产签名、打印任务持久化、结果不确定处理及补打标识尚未完成。实际试打等待用户确认。
