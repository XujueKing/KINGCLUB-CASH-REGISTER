# 单一产品迭代记录

用户确认只维护一套最终产品，界面与真实业务同步开发、验证并保留数据升级。

- 移除 CASHIER_PREVIEW 应用入口分流，登录后统一使用 KING 品牌导航、真实桌台网格和已有业务面板。旧 build-preview 脚本名仅兼容转调统一构建。
- 登录只输入账号密码；服务地址由构建配置提供，单店自动选择、多店按名称选择。员工门店名称进入会话展示。
- 桌台 minimumSeats 允许空值，与扫码点单已有每日开台规则一致；不自行补写最低人数。
- 会员、预约、存取酒未接通处明确显示当前状态。现有业务开关不因 UI 合并而自动启用；订单入口当前仍需选真实桌台。

验证：Flutter 本地测试 793 通过、5 可选跳过（不包含两份需显式环境的真实后端互操作测试）；静态分析无问题。ARM32 release 构建通过，核对原证书后 install -r 保留数据升级指定收银机，原会话恢复，现场截图确认品牌导航和真实桌台网格，无横向溢出。未执行付款、退款、核销、开台或清台。

后续同一产品迭代以统一后端的 `docs/commerce/2026-10-01-unified-business-review.md` 为业务缺口基线，按共享订单、会员归属、权益和财务链补齐。当前实时连接仍需继续排查，手工刷新可用；此轮不宣称完整营业验收。
