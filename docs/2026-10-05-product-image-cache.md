# 商品图片持久缓存

修正点单图片优先原图、仅内存缓存的问题。商品列表和消费明细共用 ProductThumbnail，优先使用 APP 同款 thumbnail 文件。

Android 将图片写入应用私有 noBackupFilesDir/product-images-v1，保留数据升级、退出重进与进程重启均保留。清除应用数据或卸载会移除。缓存键为服务地址和不可变附件路径的 SHA-256，不包含短期下载签名；附件变更产生新编号，自动读取新图。缓存文件不存签名或用户信息。

读取先内存再磁盘，缺失时 HTTPS 下载；同图并发请求合并，下载成功后原子写入。损坏图片移除后重试；下载设置超时、体积上限，禁止重定向。缓存无法写入时仍可显示已下载图片。目录位于 noBackupFilesDir，避免商品缓存进入系统备份。

验证：持久缓存实例重建、签名轮换不重下、图片编号及服务地址隔离、损坏文件重下；缩略图选择、商品卡片四语言和规格选择回归。首张未缓存图片仍需下载，已缓存图片不因目录刷新而重新下载。
