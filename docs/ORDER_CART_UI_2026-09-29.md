# 员工点单购物车增量

## 当前接入

真实桌台入口 → 1911本场次入座会员查询 → 选择可用消费会员 → 点单购物车。复用1910目录分类与分页，单独浏览目录仍只读；购物车模式增加商品选择按钮。规格来自服务器SKU快照，不创造本地规格/商品价格。

- 左侧目录，右侧购物车；支持加、减、移除、CNY整数分合计，确认弹窗逐行展示名称、规格、数量、金额、桌台场次、消费会员及付款模式。
- 未知库存/零可售不能选；每SKU最多1000件、最多50个SKU、总额最多100000000分；服务端仍重验全部价格、商品版本、库存、会员及门店权限。
- 相同SKU版本或价格变化拒绝合并，提示移除后重选。分类切换保留草稿，未发送草稿不占库存、不锁价。暂不支持套餐组合/AA共享套餐、赠送改价、打印和支付。
- 进入购物车先读取当前员工加密待确认记录；本桌已有未决请求或读取失败时不允许新下单。实际提交前控制器还会再次验证并持久化，不仅依赖页面检查。其他员工留下的同桌未决记录仍由日志写入阶段阻挡，本轮不增加跨员工查看权限。
- 必须明确确认才调用 submitOrder；原请求由既有控制器生成、加密保存读回后才发1912。确认说明先付预留、后付出库，不声称收款或扣余额授权。
- 尝试提交后当前编辑器不再创建新请求，含网络/存储失败，提供独立恢复入口。查回沿用原请求；未持久化成功时可能无待查记录，可返回重新核对，不伪造原请求存在。
- 会话变化、后台切换、场次/实时revision变化使当前选择失效。未发送草稿目前不跨场次/前后台保留，需重新选会员和商品；已发送记录保留在加密日志。确认前后检查世代与身份，迟到结果不展示到新会话。
