# 收银端场次会员选择

## 已实现

- `StaffAuthController.readOrderContext` 调用 K260929001911，门店来自员工会话，显式传桌台、场次及分页游标。发送前/响应后验证会话有效期，并以代次丢弃退出、切换后的迟到响应。
- `OrderContextSnapshot` 严格校验门店/桌台/场次、open 状态、先付/后付模式、人数（允许未知）、币种、昵称、会员可选标记、观察时间及最多 50 条的递增游标。不可将缺失字段当默认授权。
- active 桌台、open 场次且员工具备 orders.create 时显示“入座会员”入口，打开指定场次而不是隐式切换到最新场次。
- 四语言横屏会员列表：昵称为空显示未设置，失效会员不可选，选择仅暂存页面内存。分页、刷新、实时版本变化、身份通知、前后台切换及页面离开均不沿用旧选择。分页只表示本页观察，不以顾客人数生成会员。
- 返回桌台刷新工作台。错误展示通用提示，不显示数据库或通道私有错误；无会员、读取失败、尚未加载分别处理。
