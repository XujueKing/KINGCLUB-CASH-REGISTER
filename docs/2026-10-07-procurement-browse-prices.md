# 采购商品选择

进货申请左侧增加纵向商品分类，和库存/点单的浏览方向一致，搜索可叠加分类。已报价商品优先显示；“待报价”集中查看未匹配规格和供应商未报价商品。分类、搜索、加减不请求接口，不清空右侧已选清单，关闭继续取消本次未保存修改。

原库存 context 一次返回全部采购候选和分类名称；相同商品和规格按供应商独立报价，添加默认选择最低有效报价。服务器修复整桶与大件报价单位的处理，未知价格不补造。不同容量、口味、容器类型需按商品证据核对。

四种语言的触摸布局、分类搜索、清单保持和取消行为测试通过；现有采购保存、编辑、最低价选择和数量交互测试通过。ARM32 保留签名和应用数据升级，使用既有门店员工会话。
