# 门店流水账

侧栏报表后为流水账；底部只有头像，点击提供注销（结束员工会话）及退出（关闭应用，不清理草稿）。

流水账独立登记零星收入、备用金支出、员工临时垫款，不重复纳入订单营业额。金额以分传输，大数字键盘按元输入。登记必须有事由、经办人，方式可选现金、银行、微信、支付宝、其它；凭证备注选填。系统记录实际登录员工及登记时间，不将手填经办人当作授权身份。

按每日 06:00 划分营业日，可查今日、本周及日期范围。每页 50 笔，汇总覆盖整个所选范围，作废不计入汇总。待报销仅含未确认的员工垫款；已报销单列，不重复算备用金支出。

普通员工可登记和查询本店数据。审核复用门店员工授权表的 cashbook.review 权限，仅为用户此前指定的超级管理员在本店开通；可批量确认普通收支、确认垫款已报销或作废待确认记录。已确认、已报销不可再编辑或作废。报销按钮明确只记录已发生的还款，不发起转账。

一页/一动作调用 K261006002019，服务端一次 kingclub_cashbook 返回分页、汇总、权限。创建使用固定 UUID 幂等键，网络失败重试原请求，不重新生成记录。
