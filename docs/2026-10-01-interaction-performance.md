# 收银交互性能修正

收银界面由 Flutter 直接渲染，不是 WebView。已确认的等待来源包括每次请求重新建立 HTTPS 连接、同页刷新先清空内容，以及桌台和订单导航之间重复创建相同桌台页面。

本轮沿用现有接口，完成以下修正：

- 成功完整读取响应后复用连接，最多保留四个空闲客户端；并发请求独占客户端，失败或超时丢弃，退出关闭全部连接。保持证书校验、响应大小限制和交易请求不自动重试。
- 同页桌台、商品刷新保留原内容并显示进度，读取完成后替换；刷新期间禁用旧卡片选择。翻页、商品分类切换、读取失败和应用切后台仍清除相应旧内容。
- 桌台与订单导航共享现有桌台页面状态，重复点击当前菜单不重建。

验证：39 项相关测试通过，六个目标文件静态检查无问题。电脑通过真实加密接口读取，登录后首个桌台请求约 107 ms，后续商品、桌台会员和订单请求约 38–50 ms；这不是 SUNMI 点击耗时，也不是优化前后对照基准。

ARM32 release 已构建。核对目标 SUNMI 已安装 APK 与候选 APK 的签名一致后，使用保留数据升级；原员工登录状态恢复，桌台、商品分类与商品读取正常，截图确认安卓底栏仍隐藏。实机进行了桌台／订单切换、刷新及商品页读取，没有发起交易。

尚未完成：其他菜单往返仍会按需读取，尚无完整实机延迟对照；会员扫码入座、点单与 APP 实时同步仍需完成服务启用和跨端联调。本轮安装同时包含先前已提交的会员入座界面，但不代表服务端写功能已经开放。
