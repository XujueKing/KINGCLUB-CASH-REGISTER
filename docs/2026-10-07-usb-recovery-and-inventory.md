# USB 重连与库存读取修复

打印每次识别当前已接入的 XP-80U，USB 授权丢失时在这次打印内请求系统授权，并重新枚举设备与地址，不要求先进入设备设置。系统授权弹窗关闭、窗口恢复焦点后才返回授权结果，避免首次授权后仍需再点打印。新增该设备的 Android 插入过滤，系统可记住默认应用。拒绝授权、设备歧义及中途断开不发送或重发不确定的小票。

扫码盒子沿用原生 USB HID 按键拦截与 SUNMI 广播，不依赖 input 焦点或固定设备编号。新增输入设备热插拔监听，清除拔插前未完成的码和短时去重缓存；APP 回到前台恢复监听。

库存读取失败来自响应超出 1MiB：供应商目录变更流水携带完整报价目录，加密响应约 1.18MB。服务端迁移 385 恢复分类和预警字段；386 将目录变更流水改为摘要，约 67KB，完整报价和审计原文仍保留。终端增加仅输出异常类型和机器码的诊断，不记录扫码内容或凭证。

验证：24 项打印、授权、传输及库存页面测试通过；Android release 构建通过，原签名覆盖安装保留数据。SUNMI 现场库存页面显示 45 款商品和分类；补打 V1 未付款小票返回 `transport_accepted`。物理出纸与断电重连仍以现场反馈为准，软件发送成功不等于已确认纸张出完。
