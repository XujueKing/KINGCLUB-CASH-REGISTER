# 单券核销

用户要求先完成核销，AA规则后续再接。核券工作台显示官方券名称，点击确认核销调用统一接口K261005002012；无需先绑定商品、选择AA配方或关联会员。本流程不自动发酒、不增加消费商品。

每次确认固定一个requestId。未明确成功时保留原请求，按钮切换为查询结果，禁止再次扫码发起另一次核销；服务端读取原流水，不重发平台核销。只有官方单券result为0才显示核销成功。平台明确拒绝显示本次未核销成功。

门店取自登录会话。终端不能提交平台商家号、门店号、核销token和真实价格；服务器按当前门店绑定选择凭据，并冻结原商家/门店快照。
