# 结束本次收款

原支付宝收款查询返回 canCloseUnpaid=true 后，显示“结束本次收款（保留账单）”。复用员工会话、原请求日志和统一支付面板，不输入新付款码，不增加勾选。后台轮询只查询，不提交关单。页面、员工、门店或前后台上下文变化时清除按钮能力；提交前再次检查当前上下文。

新接口 K261002001962 只接受原请求六项参数；结果未知保留日志，关闭成功验证服务端原单凭证后才移除日志，账单继续待结算。该操作不取消已出酒、不清台、不退款。查询按钮不再显示原请求 UUID。
