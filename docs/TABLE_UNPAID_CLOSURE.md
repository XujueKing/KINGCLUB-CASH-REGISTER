# 整桌未付款关闭恢复（开发中）

收银沿用统一收款、查原交易入口。新增 closed_unpaid 完整回执校验：原门店、桌台、场次、员工、父单号、金额、订单指纹和数量必须匹配。仅回执通过才允许清除本地恢复记录，显示“本次收款已关闭，未付款。消费账单保留，可重新结账”；不展示已付款、不生成结算小票、不自动再次扣款。

服务端当前支持微信官方明确 CLOSED 的后付款整桌请求；交易结果不明或退款歧义仍保留原单核对。原单查到 closed 状态本身不构成关闭成功。原先未发送取消流程保持独立证明。

结果解析、恢复控制器、未决记录、结账界面 4 文件 43 项测试通过（build/postpay-close-ui-tests.log）。尚未随整个后付款批次发布或安装，不代表实际渠道交易验收。
