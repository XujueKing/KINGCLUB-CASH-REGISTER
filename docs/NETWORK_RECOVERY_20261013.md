# 桌台临时断网恢复

服务器连接暂时失败时，桌台按 5、10、20、30 秒间隔重试只读请求，之后维持 30 秒间隔，成功后停止重试并恢复实时数据。页面首次加载失败提供可触摸的刷新按钮；已有快照保留并提示未更新，桌台、会员、账单等操作冻结，避免旧数据继续交易。权限和其他业务错误仍清除旧显示，不伪装成网络断开。

页面退到后台取消待执行重试，回前台重新读取；旧请求结果继续通过版本校验丢弃。该变更不自动重发付款、改价、核销、库存等写操作，也不提供冷启动离线交易。

验证：桌台、实时客户端、会话刷新和快照 28 项测试；历史日历、整桌付款实时路由、清台实时交互 8 项测试通过。针对变更文件分析无错误或警告；ARM32 构建完成，并用项目保留证书重新签名，证书指纹匹配此前目标设备。服务器健康、就绪和运行状态检查通过。

设备已搬到门店，当前电脑没有目标 SUNMI 的 ADB 连接。新安装包保存在 `.local/releases/network-recovery-20261013/kingclub-cashier-arm32.apk`，尚未安装。安装前再次核验设备与原签名，使用保留数据升级，禁止卸载旧程序。已部署的主机资源防护和证据采样详见服务端 `docs/deployment/KINGCLUB_RESOURCE_INCIDENT_20261013.md`，故障前具体内存增长进程仍在调查。
