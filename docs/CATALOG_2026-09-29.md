# 员工商品目录接入

## 已实现

- `StaffAuthController.readCatalog` 调用统一后端 K260929001910，门店固定取已验证员工会话，仅 `orders.create` 可进入；发送前和返回后检查会话期限、会话代次。
- 严格解码分类、四语言名称与规格、价格（整数分）、商品版本、可售数量、库存已知标记及观察时间。拒绝跨店、重复/倒退游标、分类不匹配、不完整多语言及互相矛盾的库存字段。
- 桌台工作区提供商品目录入口，分类横向滚动，商品列表惰性构建，每页最多 50 项，前后分页；分类切换重新开始分页。
- 只展示服务端目录观察结果，不锁价、不预留库存、不提交订单。缺失库存记录显示“库存未知”，与已知零可售数量区分。
- 经营 WebSocket 版本改变时重新读取目录；手动刷新、回前台重新读取。读取中及失败清除旧数据，后台/身份通知清除展示，忽略迟到响应。每页独立观察，不宣称跨页同一快照。

## 验证与边界

- Flutter analyze 无问题；完整 flutter test 114 项通过、1 项可选截图测试跳过。
- 新增 8 项测试：四语言/不可变模型、门店及字段校验、库存一致性、游标分页、1910 参数绑定、权限拒绝、退出/过期迟到响应，以及 1024×600 四语言界面与分类/失败展示。
- 测试仅使用测试夹具和注入通道，不生成生产业务数据、不访问线上。此轮未安装设备、未部署后台、未执行数据库迁移或真实交易。
- 后端目录服务及 182 元数据迁移需按正式发布流程安装、授权、启用后才可实测；当前 UI 不代表服务器已启用。
- 员工下单、商品图片、会员选择、支付与团购核销仍未因本轮完成而自动可用。官方平台具体应用能力及门店授权待用户补充。
