# 横屏工作台 V1

2026-09-29：用户批准收银功能和 UI 实现。此文件覆盖 INTEGRATION_REVIEW 中“未批准实现”及独立商务分叉的旧口径。统一后端为 ccsop-service/business/kingclub-v2（合并节点 4596389e），不再在旧商务工作区编码。

## 本节点范围

Flutter 独立 Android 应用，主目标 Android 11 / armeabi-v7a / 1366×768。左侧固定导航，顶部显示门店/连接边界，主体桌台网格与右侧摘要；点单采用左订单、右分类商品。使用深绿色导航、米白画布、香槟色重点，状态同时有文字和颜色。四语言切换；低于横屏最低宽度时提示横屏使用。

桌台筛选/搜索、桌台选择、商品分类/搜索、规格选择、数量增减、逐桌独立本地购物车、草稿备注、结账核对面板、订单筛选/明细、设置中的服务就绪检查为本节点范围。

默认未连接真实经营数据，展示空状态，不制造桌台或营业额。显式进入“界面演示”后才载入内置虚构样例，常驻提示无真实交易；退出清空样例草稿。演示不发送网络请求，不修改支付、上菜或开台状态。预览构建可使用 CASHIER_PREVIEW=true，但生产默认 false。草稿仅内存保存，退出进程丢失，界面明确说明。

服务检查只对用户配置的 HTTPS 地址请求 /ready，禁止重定向，超时和响应大小受限，仅表示依赖可用，不代表已认证或可经营。不会读取手机 token，不调用登录或付款接口。员工会话、整桌订单、开台、已上、清台、打印和交班接口待后续契约实现；所有对应入口保持明确未接入，不能返回模拟成功。

## 验证要求

模型测试覆盖整数金额、规格区分、桌台草稿隔离、数量上限、清理演示数据；界面测试覆盖真实模式无样例、1366×768 和紧凑横屏、四语言、点单/结账禁止真实提交、服务地址限制。构建 armeabi-v7a APK，仅目标收银机可安装，包名不与收钱吧或 APP 重叠。安装并启动不等于业务联调验收。
